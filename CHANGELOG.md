# Changelog

## 1.0.0 (2026-11-13)

First release.

- "New Text File" in Finder's right‑click menu: on empty space, the Desktop, folders and files.
- Creates `untitled.txt`, then `untitled 2.txt`, `untitled 3.txt`, … and never overwrites.
- Builds with only the Command Line Tools (no Xcode project); signs with your Apple Development
  certificate or ad‑hoc.
- `install.sh` / `uninstall.sh` scripts and a CI build.
